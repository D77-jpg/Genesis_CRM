## 重要边界

- 商业条款来自网站公开口径，已发布供检索；具体价格、交期、运费、税费、认证溢价和付款条件仍以书面报价/合同为准。
- 认证内容仍为草稿，未逐张核对证书；使用前必须核对证书范围、有效期和最终包装设计。
- 价格区间仅作网站指引，不是报价；不要把网站区间写成客户专属承诺。
- 网站上的 “FSC-certified / GRS / GOTS-eligible / PPWR-ready” 不等于每一款成品都已认证或合规。
- 任何客户邮件仍由业务员审核后发送，系统不自动发信。

## 导入方式

通过管理员知识接口逐篇导入：产品/公司/行业/FAQ/选型/核心销售规则发布，商业条款按官网口径发布，认证合规保留草稿。发布后会触发知识索引更新；等待索引 ready 后再用于生成。
