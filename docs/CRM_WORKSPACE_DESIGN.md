# CRM 工作空间界面规范

适用于多公司客户管理、销售跟进、邮件开发，以及全部管理页面和辅助面板。

## 设计变量

- 页面底色：浅灰蓝 `--background`；工作区、表单与弹窗：白色 `--card`。
- 主色：`--primary` 蓝色，仅用于主操作、当前导航、链接与必要的焦点反馈。
- 正文、次级文字、边框、错误和业务状态均通过现有语义变量读取；不按公司覆盖公共组件颜色。
- 圆角统一为 10px，控件使用 6–8px；页面区块使用轻边框，只有浮层使用浮层阴影。
- 桌面内容最大宽度 1600px；侧栏 232px，可折叠；主区域边距 24px，手机 16px。
- 页面间距 20px，组件内部使用 4/8px 基础节奏。页头、筛选与主要内容按阅读顺序排列。
- 继承现有系统字体，不新增字体、图标或组件依赖。标题 20–24px，正文 14px，辅助信息 12px；手机输入 16px。

## 共享组件与交互

- `PageHeader`：可换行的标题与说明、统一主次操作区、详情返回入口。
- `WorkspaceToolbar`：搜索、筛选、清除与列表操作的白色工具栏；不托管任何查询状态。
- `SectionHeading`：仪表盘指标分组；指标公式与数据来源保持原样。
- `Card` / `StatCard`：工作区轻边框；统计图标使用克制的蓝色，错误保留明确语义。
- `Table`：语义化表格、排序状态、局部横向滚动，键盘可聚焦滚动区域。长公司名称不会撑大客户列，完整名称可从提示或详情查看。
- `Button` / `Input` / `Select` / `Textarea`：统一尺寸、白色输入表面、禁用和焦点反馈；手机常用操作高度至少 44px。
- `Dialog` / `AlertDialog`：轻遮罩、标题说明、可滚动正文、固定可达的底部操作。使用 Radix 原有焦点管理和关闭行为。
- 手机导航使用同一份权限过滤的导航数据，Radix 模态抽屉负责焦点约束；提供跳转到主内容入口。
- 邮件中心保留文件夹、同步状态、会话、任务与附件全部操作；宽屏并列列表和阅读区，窄屏顺序排列。
- Agent 与随手记继承相同表面、边框、阴影和文字规范；不修改保存、审批与执行规则。
- 保留已有深色模式。系统减少动态效果设置下，关闭非必要动画和过渡。

## 业务边界

这次改造仅涉及前端展示、布局和可访问性；不修改数据模型、API、权限、业务规则、统计口径或持久化机制。
公司与项目名称继续读取当前项目或服务端配置，公共组件不新增特定公司的品牌内容。
验证使用独立临时数据库与虚构资料，不替换正式数据，不启动邮件收发任务。
