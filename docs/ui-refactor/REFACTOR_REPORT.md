# 外贸 B2B CRM 全站 UI/UX 重构报告

日期：2026-10-30  
范围：`web/src` 前端界面；保留现有路由、接口、权限、项目隔离和业务数据。  
设计基准：Attio / Linear 式工作台产品：中性、克制、信息密度高、行动明确。

## 1. 完成概览

本次不是只换颜色或圆角，而是同时调整了信息架构、页面布局、层级、组件尺寸、数据密度和交互状态：

- 建立统一设计令牌：中性灰白底、单一紫色强调、8px 圆角、边框驱动层级。
- 重做应用壳：白色侧栏 + 48px 顶栏 + 全局客户搜索 + 项目切换 + 可滚动项目轨道 + 助手/随手记入口；折叠控制移到顶栏。
- 客户管理增加右侧客户速览、语义状态色谱和超宽屏整屏工作区，兼顾扫描效率与录入效率。
- 统一基础组件：`Button`、`Input`、`Select`、`Card`、`Badge`、`Dialog`、`Table`、`Tabs`、`PageHeader`。
- 按业务场景重排页面，不强行复用一种卡片模板。
- 增加窄屏卡片列表、邮件双栏、知识库双栏、发送前检查等可用的响应式/交互细节。
- 保持所有真实项目封面、品牌 Logo、客户数据和业务 API。

设计系统细节见：`docs/ui-refactor/DESIGN_SYSTEM.md`。  
Before/After 截图索引：`docs/ui-refactor/screenshots/README.md`（含本地客户信息，仅保留在工作区，不提交到公开仓库）。

## 2. 分页面完成情况

### 2.1 销售工作台

- 4 个指标从独立卡片改为一条带 1px 分隔线的指标带；移动端 2×2。
- 客户工作清单与工作提醒组成主工作区，业务分析收为底部可折叠区。
- 工作清单行高压缩，头像改为中性方块，状态文字中性化，仅保留逾期等语义色。
- 主操作收敛为刷新 / 今日开发 / 客户管理。

### 2.2 客户管理

- 页头统一为标题 + 客户数量 + 导入/导出/新建三个动作。
- 第一行搜索、状态、跟进、负责人；标签、国家、行业、来源、优先级、等级收进“更多筛选”。
- 表格改为 13px 紧凑表格，客户身份优先展示姓名，公司和行业为次级信息。
- 1360px 及以上增加 320px 右侧“客户速览”：显示真实联系方式、负责人/来源、最近联系、开发信数量、下次跟进、标签和备注，并可直接发送开发信/编辑。
- 行点击切换速览并高亮当前行；姓名链接和面板底部入口继续进入完整客户资料；面板可关闭，关闭后点击任意行重新打开。
- 速览默认选中第一条，不新增假页签或额外请求；完整跟进、邮件、文件等信息仍由详情页承担。
- 1280px 以下自动切换为客户卡片，避免平板横向裁切；390px 下已验证无横向溢出。
- 1360–1799px 打开速览时隐藏低优先级列（开发信/下次跟进/最近联系），1440px 起恢复负责人列，避免表格挤压。
- 客户状态改为低饱和语义色谱：待跟进 slate、已联系 sky、已回复 emerald、有意向 amber、报价中 orange、谈判中 violet、已成交 emerald、已流失 rose；等级、来源、标签保持中性。颜色始终与文字/圆点同时出现，不是唯一的识别方式。
- 取消全站 1480px 内容宽度上限，主工作区始终使用可用宽度，左右只保留 16px 页面内边距；表单/设置页继续用自身 max-width 保证可读性。
- 表格最大高度随视口提升到 68rem，减少超宽/高屏外围空白。

### 2.3 客户详情

- 头像改中性 32px 方块；客户名、公司/行业/国家形成清晰身份区。
- 原 5 个页头动作收敛为“生成草稿”下拉 + 主操作“发送开发信”。
- 草稿审核区压缩为一行标题 + 待处理/不通过筛选 + 刷新；空态缩短。
- 客户信息、联系方式、客户需求保持三块业务卡，但降低内边距和标题层级，字段密度提高。
- 生成草稿菜单保留快捷生成首封、补齐三封、整理当前草稿、删除客户等原功能。

### 2.4 今日开发 / 线索

- 4 个独立指标卡改为指标带；桌面 4 列、移动端 2×2。
- “我的今日开发 / 公共池 / 团队”改为下划线页签；状态过滤改为紧凑分段文字。
- 线索卡统一为 8px 圆角、无阴影、紧凑内边距；分数、来源、公共池、日期、操作重新排序。
- 去掉了与分组标题重复的“待补联系方式”状态标签。
- 保留领取、转为客户、跳过、批量补全、搜索设置等完整流程。

### 2.5 邮件中心

- 去掉外层两张悬浮卡片，改为统一的全高双栏工作区。
- 文件夹切换改为下划线导航，状态条改为扁平边框行。
- 左侧列表独立滚动，右侧会话独立滚动；桌面固定高度，移动端自然堆叠。
- 邮件会话使用分隔列表而非重复卡片；追踪统计、正文、附件按信息层级排布。
- 空态在右侧垂直居中；发件记录选中会话、邮件互动、邮件会话助理均已验证。

### 2.6 开发信记录

- 页头、搜索、状态、发送方式筛选统一为紧凑工具栏。
- 表格行高、字号、状态标签中性化；导出 Excel 为唯一主操作。
- 保留分页、批量选择和全部既有字段。

### 2.7 知识库

- 增加统一 `PageHeader`；视图切换改为下划线页签。
- 资料分类从“填充色胶囊按钮”改为文本导航 + 计数，当前分类使用下划线。
- 资料列表/正文保持双栏，搜索框、刷新、管理资料入口压缩。
- “先看适用范围”从紫色大色块改为中性说明块，紫色只保留在必要强调处。

### 2.8 产品 / 规格 / 价格

- 统一页头，刷新 / 下载模板 / 批量导入 / 新增产品保持可用。
- 3 个统计项压缩为指标带，字号和间距统一。
- 搜索、状态筛选、空态重新设计；空态提供批量导入和新增产品两个明确入口。
- Excel 导入流程、模板下载、产品表格字段和权限保持不变。

### 2.9 项目工作空间

- 移除重复说明大卡片，改为一行辅助说明。
- 保留真实 Genesis / IRONHUE / VELATURO 封面，封面高度压缩为 112px。
- 项目卡改为紧凑信息顺序：封面 → 名称/行业 → 公司主体 → 渠道/默认 → 操作。
- 当前项目仅用细边框和状态点表达；项目轨道使用独立方形图标，VELATURO 使用提供的“画家 + 画架”插画裁成方形图标，不再把横向字标压进小方框。

### 2.10 模板中心

- 模板效果从固定大卡片改为可折叠区域，默认不占用首屏。
- 模板卡保留分类、名称、主题、正文摘要、更新时间与编辑/复制/建议副本/删除操作。
- 模板筛选、搜索、新建、建议副本、删除确认全部保留。

### 2.11 用户管理

- 账号行改为中性方形头像；角色/状态标签中性化，仅“启用”保留低饱和绿色语义。
- 行内保留编辑、重置密码、配置发件邮箱、停用/启用、删除菜单。
- “当前登录”使用轻量 muted 标签，不用抢眼彩色胶囊。

### 2.12 AI 使用情况 / AI 配置

- AI 使用情况：统一页头、4 项使用指标、按用户表格、自检和异常记录；实际路由为 `/agent-diagnostics`，已验证。
- AI 配置：改为最大 920px 的“左侧当前配置 + 右侧单列表单”，压缩表单间距和输入高度；现有配置、密钥状态、连接测试、保存逻辑不变。

### 2.13 弹窗 / 抽屉 / 表单

- 共享 `Dialog` 统一 8px 圆角、紧凑内边距和底部操作区。
- 发送开发信弹窗重排为“客户/发件人摘要 → 邮件内容 → 右侧发送设置 + 发送前检查”。
- 去掉无内容时产生的空白知识审核区；新增发送前检查：收件人、主题正文、发件邮箱、占位符、发送时间。
- 销售助手抽屉去掉渐变头图和紫色欢迎大卡；改为中性头像、下划线式功能切换、紧凑消息气泡和底部输入框。
- 个人随手记抽屉保留笔记编辑、AI 整理客户和复制/清空能力，统一边框和中性命中态；抽屉头部改为 48px 工具条，原先的紫色 AI 卡片改为中性说明块。

### 2.14 侧栏项目区

- 移除了侧栏底部占一整行的“折叠侧边栏”文字按钮，折叠/展开改为顶栏左侧的图标按钮，带 tooltip 和 `aria-label`。
- 项目轨道限制为最高 10rem，项目多时在轨道内独立滚动；项目总数显示在“项目”标题右侧，当前项目切换后自动滚入视野。
- 顶栏项目切换器的下拉列表限制为 `min(24rem, 70vh)`，项目数量增加时不会撑破视口。
- 紧凑项目图标使用独立方形图标：Genesis / IRONHUE 使用既有图标；VELATURO 使用提供的“画家 + 画架”插画裁成方形图标，避免把横向字标压进 24px 方框。

## 5. 未解决 / 需要说明的问题

1. **`server test:mail` 的 1 项失败是测试数据假设，不是 UI 回归。**  
   失败用例期望项目目录只有 `genesis-bags`、`ironhue`，当前本地数据库多了一个真实项目 `velaturo`。实际集合为 3 个。建议在干净测试库执行，或把该断言改为按测试 fixture 动态读取项目集合；本次没有为了通过测试而删除 VELATURO 数据。

2. **真实邮件发送未被 UI 冒烟测试触发。**  
   当前账号未配置个人发件邮箱，发送弹窗正确显示“不可发送”并保留审核/存草稿能力；SMTP、定时任务、失败重试由 `server test:mail` 覆盖。

3. **VELATURO 的单独图标来自提供的独立插画。**  
   项目卡继续使用完整 VELATURO 字标/封面；项目轨道等 24–28px 紧凑位置改用提供的“画家 + 画架”插画裁成的方形图标（`web/public/project-icons/velaturo.png`），没有伪造或重绘品牌。未知且无图标的项目才使用中性字母回退。

4. **截图数据会变化。**  
   截图基于本地真实数据（客户数、线索数、最近登录时间等），不是固定假数据；报告中的数字只用于说明密度和布局。

5. **未覆盖所有历史弹窗的逐像素截图。**  
   共享 Dialog/Button/Input/Select/Table 的规则已统一应用；已重点人工检查发送开发信、销售助手、随手记、客户详情和客户表单相关结构。若后续新增页面，应直接复用 `PageHeader` 与共享组件，不要重新引入旧的 `rounded-3xl`/渐变写法。
