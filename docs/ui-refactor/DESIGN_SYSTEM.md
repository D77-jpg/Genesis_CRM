# GlobalCRM 界面设计系统

## 1. 设计方向

这次改版以 Attio / Linear 的工作台式产品为参照，但只借鉴其**信息秩序、密度和克制感**，不复制其品牌。

- **内容优先**：页面先回答“现在要做什么”，再展示统计和辅助信息。
- **边界优先**：用 1px 分隔线、留白和字号建立层级，不用大面积渐变、悬浮阴影和装饰性色块。
- **受限语义色**：紫色只用于主操作、当前项和需要用户注意的核心动作；客户状态使用低饱和语义色，普通标签、来源、等级保持中性。颜色只做第二层提示，文字和圆点始终是主信息。
- **场景化布局**：客户列表、详情、邮件中心、知识库、项目空间分别采用列表、双栏、工作区、卡片等不同结构，不把所有内容都塞进同一种卡片。
- **移动端保留触控尺寸**：桌面端压缩到 28–32px 控件，移动端仍保留可点击面积；表格在窄屏切换为信息卡，避免横向裁切。

## 2. 基础令牌

| 项目 | 值 / 规则 |
| --- | --- |
| 页面背景 | `hsl(240 10% 97%)`，浅灰、无渐变 |
| 内容面 | `hsl(0 0% 100%)`，白色卡片/面板 |
| 主文字 | `hsl(240 10% 7%)` |
| 次文字 | `hsl(240 4% 45%)` |
| 边框 | `hsl(240 6% 90%)` |
| 主色 | `hsl(252 62% 58%)`，仅用于主按钮、当前项、关键动作 |
| 状态色 | 待跟进 slate、已联系 sky、已回复 emerald、有意向 amber、报价中 orange、谈判中 violet、已成交 emerald、已流失 rose；全部为低饱和语义色 |
| 内容宽度 | 主工作区默认使用 100% 可用宽度，只保留 16px 页面内边距；表单/设置页用自身内部 max-width 控制阅读宽度，不再用全局 1480px 上限制造外围留白 |
| 圆角 | `--radius: 0.5rem`；按钮/输入 6–8px，卡片 8px，弹窗 8px |
| 阴影 | 仅弹层和浮动侧栏使用低透明度阴影；普通卡片基本无阴影 |
| 字体 | 系统无衬线；正文 13px，辅助 11–12px，页面标题 20–22px |
| 数字 | 统计、数量和表格数字使用 `tabular-nums` |
| 图标 | Lucide，16px 为主；语义图标不替代文字标签 |

## 3. 组件规则

### 按钮

- 默认高度 32px；紧凑场景 28px；图标按钮 28px。
- 主按钮只保留一个；次级动作用描边或 ghost。
- 危险操作使用 destructive 色，不把删除做成普通主按钮。
- 所有按钮有 hover、focus-visible、disabled、loading 状态。

### 输入与筛选

- 输入框高度 32px，字号 13px。
- 筛选控件高度 28–32px；搜索、状态、负责人放在第一行，低频筛选项收进“更多筛选”。
- 不使用整排胶囊式筛选；状态切换优先使用下划线页签或紧凑分段控件。

### 表格

- 表头 36px，行高约 44–52px；13px 正文，表头 11–12px。
- 行 hover 使用极浅灰，不使用紫色整行高亮。
- 客户表在 1280px 以下切换为卡片列表；1360px 以上提供右侧客户速览，左侧表格隐藏低优先级列。
- 表格中的状态使用“文字 + 小圆点 + 低饱和底色”的语义谱；其他标签、来源、等级保持中性，避免每个标签都着色。
- 表格最大高度随视口扩展（最高 68rem），超宽/高屏不固定卡在 780px，减少内容区底部空白。

### 客户速览

- 1360px 及以上，客户列表右侧固定 320px 速览面板；列表与面板在同一网格内等高，不额外悬浮。
- 面板只读取列表已有的真实客户字段：身份、状态/优先级/等级、联系方式、负责人、来源、最近联系、开发信数量、下次跟进、标签、备注。
- 行点击切换速览并高亮当前行；姓名链接和“打开完整客户资料”仍进入完整详情，不改变原有路由。
- 面板默认选中第一条；右上角可关闭；关闭后点击任意行重新打开。
- 1280px 以下不渲染面板，行点击进入完整详情；移动端继续使用客户卡片列表。
- 不在面板里造假页签或重复请求；完整资料、跟进、邮件、文件等仍由详情页承担。

### 页头

- 统一使用 `PageHeader`：标题、简短说明、右侧操作区。
- 详情页返回链接放在标题上方，不与页面标题争夺层级。
- 页头不重复侧栏/顶栏已有的页面名。

### 弹窗与抽屉

- 统一 8px 圆角、白色内容面、紧凑内边距。
- 复杂弹窗采用“主编辑区 + 右侧检查栏”；右侧栏只放审核依据、发送设置、发送前检查。
- 侧栏抽屉与主内容同一套边框、字号、按钮规则；避免渐变头图和大面积紫色欢迎卡。
- 空状态必须解释下一步动作，不只显示一个图标和一句“暂无数据”。

### 导航

- 侧栏为白色，分组使用 10px 大写字距标签；当前项使用中性灰底，不用紫色整块。
- 顶部栏只保留侧栏折叠、项目切换、全局客户搜索、模拟发送状态、助手、随手记、主题、用户；折叠控制不再占用侧栏底部。
- 侧栏项目区最高 10rem，独立滚动；项目增多时不会挤压主导航，当前项目变化会自动滚入视野，顶部显示项目总数。
- 项目切换器下拉列表限制在 `min(24rem, 70vh)` 并独立滚动，项目再多也不撑破视口。
- 项目切换器和项目卡使用真实项目字标/封面；项目轨道与折叠态使用独立方形图标。VELATURO 使用提供的“画家 + 画架”独立插画裁成方形图标，避免把横向字标压进 24px 方框；无独立图标的未知项目才使用中性字母回退。

## 4. 页面模式

| 页面 | 主要结构 |
| --- | --- |
| 销售工作台 | 4 列指标条 → 客户工作清单 + 工作提醒 → 可折叠业务分析 |
| 客户管理 | 页头 → 搜索/状态/跟进/负责人 → 高级筛选 → 桌面表格 + 右侧客户速览（≥1360px）/窄屏卡片 |
| 客户详情 | 返回 + 客户身份 + 两个主操作 → 紧凑草稿审核 → 客户信息/联系方式/需求卡片 |
| 今日开发 | 指标条 → 范围页签 → 状态过滤 → 线索卡片（分数、来源、联系方式、操作） |
| 邮件中心 | 页头 → 文件夹下划线导航 → 状态条 → 左右双栏独立滚动 |
| 开发信记录 | 页头 → 搜索/状态/发送方式 → 高密度表格 + 底部分页 |
| 知识库 | 页头 → 视图页签 → 搜索 + 文本分类导航 → 资料列表/正文双栏 |
| 产品价格 | 页头 → 3 项统计 → 搜索/状态 → 表格/空态导入入口 |
| 项目空间 | 页头 → 说明文字 → 带真实封面的紧凑项目卡 |
| 模板中心 | 页头 → 搜索/分类 → 可折叠模板效果 → 模板卡片网格 |
| 用户管理 | 页头 → 单行账号列表 + 行操作菜单 |
| AI 使用情况 | 页头 → 4 项使用指标 → 按用户表格 → 自检与异常记录 |
| AI 配置 | 页头 → 当前配置摘要 + 单列表单（最大 920px） |

## 5. 交互与可访问性

- 全局搜索 `Ctrl/Cmd + K` 聚焦；`Enter` 将搜索条件应用到客户列表。
- 客户列表行点击：≥1360px 切换右侧速览；<1360px 进入完整客户详情。姓名链接始终进入详情。
- 助手 `Ctrl/Cmd + Shift + A`；随手记 `Ctrl/Cmd + Shift + M`。
- 发送弹窗 `Ctrl/Cmd + Enter` 发送，`Ctrl/Cmd + S` 存草稿。
- 所有图标按钮提供 `aria-label`；页签提供 `aria-current`；筛选按钮提供 `aria-pressed`。
- 键盘焦点环使用 2px ring，保证在浅色/深色主题下可见。
- 深色主题保留同一套层级：深色背景、深色卡片、低对比边框，避免彩色大面积反白。
