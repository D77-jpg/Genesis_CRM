# 客户列表直接编辑验收（2026-10-14）

基于 Genesis_CRM main `1586a43`，分支 `codex/customer-inline-edit`。

客户列表的状态与负责人改为行内下拉选择，选择后通过既有客户更新接口保存。
请求只携带本次选择的字段；不提交整份客户表单。管理员可指定或清空负责人，业务员只能修改已授权客户的状态。
保存期间禁用快速编辑与批量操作；失败在对应字段显示错误，并保留原值。成功后刷新列表以匹配当前筛选与排序。
桌面表格与手机卡片共用控件，选择操作不触发行/卡片的详情跳转。

已验证：

- 类型检查、最终前端构建、三个改动文件的 ESLint 检查、git diff --check 通过。
- 浏览器使用独立临时 MongoDB 与真实 Express API，状态修改、负责人分配、清空负责人以及刷新恢复通过。
- 读取真实测试 API，客户姓名、公司、邮箱、手机、国家、等级、标签及备注保持原值。
- 在“已联系”筛选下改为“已回复”，客户退出当前筛选列表。
- 375px 手机卡片直接修改状态并保存通过。
- 单次真实 HTTP 503：原状态保留、字段下显示错误、再次选择后保存成功且错误清除。
- 业务员登录：负责人控件不可见，归属自己的客户状态修改成功。

测试使用虚构客户，没有编辑现有客户、启动邮件任务或发送邮件。
现有 5173 服务仍运行原功能分支；本分支通过 5174 提供独立预览，人工开 PR 合入 main 后再更新正式入口。
