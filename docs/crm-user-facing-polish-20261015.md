# CRM 排版与用户文案优化

## 问题与调整

Agent 表单标签原先紧贴输入框，标签行高过小；导航与模型状态共用一行，较窄面板会挤压换行。公共提示条采用横排布局，也会让标题和说明互相挤压。

本次统一标签行高；批量写信、自动准备、产品资料表单使用明确的字段间距、自然换行与足够点击区域。助手六个常用入口保持两行三列，状态移入标题区；已有分析可从“查看最近分析”重新打开，当前分析入口仍明确显示。公共提示条标题与说明改为上下排列。

检查并调整了 Agent、客户分析、邮件分析、模板建议、邮件预览、个人邮箱、项目设置和 AI 配置等页面的用户文案。移除应用阶段版本号和没有校准依据的置信度百分比；不再直接展示内部工具名、原始错误代码、draft 等内部状态词及服务器配置变量。管理员页面以“AI 使用情况”和“功能检查”描述维护功能。

AI 用量、单任务上限及记录范围仍可展开查看。真实发送与演示模式区别、邮箱连接参数、资料发布版本、停止联系提示及人工确认边界继续明确展示。自动准备规则的保存按钮仅在有修改时启用，避免重复保存打断任务。

## 本地验证

- 375px 手机宽度与 1440px 桌面宽度均无横向溢出。
- 批量表单三个主要字段的标签/输入间距均为 8px；导航按钮高度 44px。
- 邮件分析提示条的说明在标题下方，不再并排挤压。
- 从“操作记录”打开详情、从“最近分析”打开已有结果、展开高级用量设置均正常。
- 前端构建（含类型检查）通过；服务端类型检查通过。
- Agent 62 项、前端现有 28 项回归通过。此次页面验证未调用模型、发送邮件或修改客户资料；测试项目自动规则保持关闭。

本改动为用户界面和说明整理，不删除历史会话、客户资料、已保存草稿或操作记录。历史模型回复属于已有内容，不批量改写。
