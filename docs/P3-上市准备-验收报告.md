## 1. 验收结论

**代码与可自动验证项：通过。** 主流程 E2E、迁移框架、公开页面、帮助中心、价格页、安全基线和本地压测均已落地并有测试或运行证据。

**正式公开上市：仍有三项人工/外部门禁未完成，不能宣称已全部完成：**

1. 独立第三方渗透测试未执行；仓库提供范围、规则和签收清单。
2. 法律文件仍是上市模板，主体名称、地址、管辖地、子处理者和 SLA 承诺需律师复核并替换占位符。
3. 24–72 小时 staging 长稳、生产同构容量测试、真实 IMAP/SMTP 与支付/开票流程演练未在本会话执行；当前只有本地 30 分钟稳定性和 30 秒压力证据（另见压力报告）。

## 2. 主流程 E2E

命令：

```powershell
npm run test:p3 --prefix server
npm run test:e2e --prefix server
```

实现：`server/tests/p3-main-flow.test.ts`，使用真实 HTTP、cookie/CSRF、内存 Mongo；流程：

`登录 → 导入客户 → 发送开发信（mock）→ 收到并匹配回复 → 报价 → 客户状态 quoting → 时间线校验`

结果：**5/5 通过**（包含 4 个迁移测试 + 1 个主流程）。  
边界：入站回复通过 `mail-sync.importMail` 解析器注入，不连接真实 IMAP/POP3；mock 发信不投递外部邮箱。真实邮箱 E2E 需要在 staging 单独执行。

## 3. 数据库迁移与三套环境

已实现：

- `server/src/migrations/001…007`，前向、追加式；`schema_migrations` 记录 `id/version/name/checksum/duration/batch`。
- `migration_locks` advisory lock，TTL 2 小时；并发 runner 被拒绝。
- `npm run migrate` / `migrate:status` / `--dry-run` / `--to`。
- API 与 worker 启动改为 `assertMigrationsApplied()`，不再执行任何迁移、`Model.init()` 或 `syncIndexes()`；有 pending/changed 时 fail closed。
- Compose 新增一次性 `migrate` 服务，`server`/`worker` 使用 `service_completed_successfully` 依赖。
- `staging.env.example` 与 `production.env.example` 独立数据库、密钥、端口、域名；开发使用 `server/.env.example`。
- `APP_ENV` 区分 development/staging/production，`NODE_ENV` 继续控制运行时安全行为。

验证：

```text
npm run migrate:status --prefix server  → 7 个迁移均 applied
node server/dist/scripts/migrate.js --status → 通过（编译产物可用）
docker compose --env-file production.env.example config --quiet → 通过
docker compose --env-file staging.env.example config --quiet → 通过
```

未验证：本机 Docker 无法访问 Docker Hub，`docker compose build` 在拉取 `node:22-bookworm-slim` 时网络失败；需在有镜像仓库访问权限的 CI/构建机执行。该失败不是 Dockerfile 编译错误。

## 4. 价格、帮助、法律与公开接口

- `/pricing`：三档套餐、月付/年付切换（年付 = 10 个月）、额度对比、超额单价、FAQ、申请试用邮件入口；明确标注人工开票、无在线支付/自动续费。
- `/help`：9 个分类、10 篇中英双语文章，搜索与分类过滤。
- `/legal/terms|privacy|dpa|sla`：四份中英双语上市草稿；主体/地址/管辖地使用显式占位符。
- `GET /api/public/plans`：无鉴权只读套餐目录，不包含组织、用户、密钥或用量；返回 3 档套餐和 `annualPriceUsd`。
- 登录页页脚、公共页脚、用户菜单均加入帮助/价格/法律入口。

浏览器验证（Playwright，`http://localhost:5175`）：

- `/pricing`、`/help`、`/help/import-customers`、四个法律页：HTTP 200，标题正确，无页面错误；
- 1280px 和 390px 均无横向溢出；
- 价格页 3 张套餐卡、年付价格显示、搜索过滤 1 篇文章；
- 英文切换后标题分别为 Pricing / Help center / Terms of Service；
- 登录后打开客户开发信编辑器，Quill 编辑器和工具栏可见，无 Quill 格式警告。

## 5. 安全

```text
npm run test:security --prefix server → 19/19 通过
npm run security:audit --prefix server → 0 vulnerabilities
npm audit --omit=dev --prefix web → 1 low（Quill 2.0.3，无修复版本）, 0 moderate/high/critical
```

覆盖：安全响应头、未登录 401、CSRF 403、Cookie 属性、租户/跨项目隔离、公共套餐接口无敏感信息、错误无堆栈；另沿用既有上传、2FA、密码策略、审计和邮件凭据脱敏测试。

风险记录：Quill 2.0.3 HTML 导出 XSS 为 low；编辑器仅受信内部使用，服务端外发 HTML 经 `safeMailHtml` 清洗，持续跟踪上游。外部渗透测试未执行，清单见 `docs/P3-安全测试与外部渗透测试清单.md`。

## 6. 压力与稳定性

本地单进程只读压测（`server/scripts/load-test.ts`）：

| 场景 | 请求 | RPS | p95 | 错误率 |
| --- | ---: | ---: | ---: | ---: |
| 30 秒 / 20 并发 | 13,125 | 468.28 | 103.9 ms | 0% |
| 5 分钟 / 15 并发 | 150,939 | 508.17 | 71.5 ms | 0% |
| 30 分钟 / 15 并发 | 1,027,888 | 571.04 | 65.9 ms | 0% |

30 分钟期间 RSS 151.8 → 356.1 MiB（冷启动后，后段约 390 MiB），heap 77.1 → 133.4 MiB；跨过 15 分钟 access token 过期并通过 refresh 续期，全部 1,027,888 个请求均为 HTTP 200。详见 `docs/P3-压力与稳定性测试报告.md` 与 `docs/P3-load-soak-30m.json`。

未完成：24–72 小时 staging 长稳、真实写入/发送/上传/AI 混合负载、生产规格容量规划。默认 600 次/分钟限流已验证会返回 429；压测只在隔离端口临时提高上限。
