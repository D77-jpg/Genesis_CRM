# S6 / ADR-006：知识治理与草稿审核

基线 main：4894e47（S5 PR #36）。沿用 Mongo 发布版本、S1 原文/解析/片段、S2/S3 索引、S4 事实审核和 S5 任务。不引入外部知识库平台。

## 管理员操作

1. 在当前项目的「知识库 → 知识条目」按产品、分类、发布状态、有效期筛选。有效发布版本与未发布修改分别标注，保存草稿不影响线上发布依据。
2. 「维护提醒」查看30天内到期/已过期、相同正文及疑似政策冲突。点击条目会清除阻碍定位的筛选并展开正文。提醒是核对线索，不是自动裁决。
3. 「查看历史版本 → 比较历史版本」选择两个版本，逐字段比较正文、产品、适用范围、使用权限、条件记录和有效期。条件记录用业务语言展示，保留边界、排除条件、币种与证书覆盖。
4. 「修订 / 替换版本」追加修订；来源关联与旧版本保留。逐条核对后发布。已确认条件必须勾选范围审核，认证承诺必须填证书覆盖产品与有效期；待确认条件可作为待审核说明保存，不能成为正式承诺。
5. 「批量停用资料」最多20条，先预览明确标题/版本与影响，再确认；不提供批量发布。预览10分钟有效、绑定项目及管理员，版本变化项跳过并报告。停用不可作为新邮件依据，旧稿提示依据变化。历史记录保留。
6. 「资料导入与审核」按文件名、关联知识的产品、分类、解析/审核状态和有效期筛选；文件分页加载，页面明确筛选的是已加载资料。解析完成与人工发布、索引就绪分别显示，不能互相替代。「检索准备」负责实际完整性与当前版本核验。

## 业务员审核

- 草稿顶部给出已回答/待确认问题数量、依据数量和下一步；区分没有匹配、已过期、来源冲突、检索故障、索引未就绪/落后、部分草稿。
- 「内部审核信息」按需展开问题、缺口、关键承诺、精确引用和适用性；不使用置信度百分数或高置信度文案。
- 「查看生成时的相关片段 → 查看来源」打开来源对话框：标题/版本、产品与条件、有效期、来源和生成时的正文快照。关联S1片段时给出页码、段落/表格或工作表/单元格位置。
- 原文件下载仍仅管理员可用。业务员只看有权访问的发布范围，不能借引用看到未发布的相邻原文；管理员可打开独立标签页，定位指定解析版本与具体片段，自动翻至正确分页、高亮并设置键盘焦点。
- 「核对资料是否更新」只刷新依据状态，不覆盖编辑内容；「按最新依据重新生成」另存新稿，保留原稿和当前未保存编辑。重生成明确保留五类邮件用途及原线程，幂等重复点击不新增同一份草稿。
- 编辑主题或正文后提示重新复核；复核明细默认折叠，服务不可用时明确待人工确认，不当作通过。发送人/收件人仍在既有发送框核对，客户邮件预览不加入内部审查材料，发送仍由业务员操作。

## 接口与状态合同

- GET /agent/knowledge-governance：管理员、当前项目、最多500条维护分析，超限明确标记。当前索引概况只提供管理状态，不冒充磁盘完整性验证。
- GET /agent/knowledge/:id/diff?from=N&to=M：管理员、当前项目的两个不可变修订差异。
- POST /agent/knowledge-governance/disable-preview：严格ids数组，1–20项；持久保存KnowledgeGovernancePreview，TTL清理不替代显式过期检查。
- POST /agent/knowledge-governance/:id/disable：重新核对当前角色/项目/预览所有者；逐条以版本CAS停用，结果持久记录。AgentKnowledge.lastGovernanceOperationId恢复停用已写入、结果日志尚未写入的进程中断；重复提交不再次递增版本。不是多文档事务，不宣称全有全无；冲突逐条报告。调用原knowledgeIndexChanged，检索仍以Mongo当前发布/停用/权限为权威。
- GET /agent/knowledge-drafts/:id/evidence?sourceId=...：先核对草稿客户权限，只接受此稿已有来源；复核当前知识权限与历史修订权限，组装后再次复核。原文片段同时绑定项目、文档与解析版本。私有引用不能因发布新的公开版本而变成公开历史。
- GET /knowledge-documents/:id?revision=...&chunk=...：保持管理员权限。服务端按目标片段ordinal确定分页，不由前端猜页数；拒绝跨项目、跨解析版本和不存在的目标。
- 普通业务员邮件列表不附带整份证据包/复核历史；详情重新核权。旧稿中的私有来源、引用与关联事实会脱敏，受限历史复核不返回。原稿正文作为既有业务记录保留，不静默改写。

## 迁移与边界

无需重写知识、原文、片段、发布/索引版本或草稿。新操作记录是旁路治理数据；旧条目的新增修订在发布时适用新确认门禁。82条真实草稿保持原样，不自动发布或补填政策。

重复检测基于空白/大小写规范化后的正文哈希；疑似冲突只比较相同主题、产品和完整显式条件下的不同值，不能覆盖语义改写、隐含条件和全库复杂冲突，实际任务仍使用S4适用性核验。到期提醒在读取时计算，不发送通知。完整自动化容量/并发/备份恢复与多实例审计留待S7，未降低原S0指标。

引用可以定位已保存的解析片段，并提供管理员原文下载；尚不提供浏览器内PDF坐标框选或Office在线编辑。缺失原文关联时明确展示发布正文快照，不伪造页码。持久预览中断恢复由确定的写入间隙回归验证，S5杀进程任务测试继续通过；本轮未把预览服务真实崩溃/多机压测作为已通过项。
