# C2 集成凭证管理

日期：2026-11-05。仓库仅 GlobalCRM，分支 feat/globalsite-c2-credentials。GlobalSite 不改动。接口唯一机器定义仍是 integration-v1.openapi.yaml；同目录 globalsite-对接设计.md 解释对接行为。本文件记录部署及安全边界，不另维护接口字段定义。

## 客户操作

在“项目工作空间”选定项目，点击“集成与连接”，或从管理导航进入。项目管理员及本组织管理员可新建、查看、轮换、吊销凭证并查看近30天集成请求摘要；销售与只读账号没有入口，也无法直接调用后台接口。所有管理调用必须有 CRM 用户会话（Cookie写入带CSRF，兼容旧用户JWT）和明确的项目头；服务凭证不能管理凭证。

“GlobalSite 连接”预选七项权限；按用户明确确认，inquiries:write 保留预选并标明待开放。设置接口同时返回 available:false。它是可签发的预留权限，不表示 /globalsite/inquiries 或其他询盘归档接口已经实现。客户可手动调整范围；脚本省略 --scopes 时仍是原有五项权限，避免新枚举自动扩大默认授权。

创建或轮换成功后仅本次弹窗显示明文，可复制；关闭、刷新或离开页面后不能取回。若响应丢失，刷新列表后重新轮换，不能通过日志或接口重放找回。明文只在组件内存和当次 no-store 响应中，不进 URL、浏览器持久存储、全局 store、数据库、审计或截图。复制操作只把用户主动选择的令牌送入剪贴板。

列表展示名称、权限、创建人、创建时间、最后使用、到期和状态。旧脚本没有创建人、或用户已删除时显示“脚本或已删除用户”；不伪造创建人。只显示全部绑定项目均在管理员权限内的凭证；跨项目旧凭证的轮换/吊销弹窗明确提示影响项目总数，不泄露其他组织项目。日志只返回时间、方法、路由模板、状态码、耗时和稳定ID，不返回请求体、token、外部业务ID或查询参数。

## 轮换和吊销

轮换保持 credentialId，保证幂等记录、请求日志、绑定项目与限流身份连续。数据库存当前 SHA256、上一个 SHA256 和 previousValidUntil；原 tokenPrefix 仅保留原有脱敏用途，不提供完整令牌。UI默认24小时，可选0、1小时、24小时、7天；API允许0..604800秒，实际宽限不超过凭证到期时间。脚本不指定宽限时仍为0，与旧立即轮换行为兼容。

宽限期内新旧令牌都可用；服务端时钟到截止瞬间，旧令牌即失效，不依赖定时清理。宽限期中不能再次申请非零宽限；用户可明确选择“立即失效”终止旧链再轮换。轮换采用 tokenHash+active CAS，并发只有一方成功；吊销清除旧哈希且将整条凭证设为revoked，新旧立即失效，不能被并发轮换重新激活。到期凭证不允许轮换。

创建、轮换、吊销由 UI 和脚本共用 integration-credential.service，均调用现有审计服务，只写操作人、凭证/项目ID、权限、宽限时间等元数据；列表与日志查看另记审计。沿用现有审计服务的失败处理，不在异常日志中输出凭证或请求体。

## 套餐与并发

有效凭证上限每项目 Starter 3、Growth 10、Enterprise 50；Organization.limits.integrationCredentialsPerProject 可覆盖（1..1000），平台组织更新接口接受该配置，无价格调整。旧组织没有新字段时按实际套餐回退，不按入门版误算。吊销/到期不占位；轮换同一记录不额外占位；降低上限不自动吊销已有连接。

新凭证的 seatKeys 为 organizationId:projectId:slot，所有绑定项目的席位在同一次凭证插入中由唯一多键索引原子占据，避免“先数后建”的并发超额。没有seatKeys的旧有效凭证仍计入占用。过期记录在下次创建前退出唯一席位索引，但不改其历史公开status；列表推导显示expired。无需新集合或Mongo事务/副本集，不重命名任何现有集合。仅受控旧脚本保留无组织历史项目兼容；后台不开放这些未归属项目。

## 上线迁移

在可信服务端、同一版本代码下执行；不要把真实凭证复制到工单、命令参数或Git。

```sh
# server 目录；先停止旧版本凭证创建脚本，再迁移并部署新API。
npm run integration:credential -- migrate
```

迁移仅为所有绑定项目都明确属于同一组织的旧凭证补 organizationId；保留ID、现有令牌哈希、scope、项目、到期和状态。跨组织、缺项目或未归属记录保留不动并计数，交由运维处理，不擅自认领。旧请求日志缺组织字段时按明确的所属项目补齐。之后创建凭证席位唯一索引、旧哈希查找索引和日志组织/项目/时间索引。可重复执行；不删除记录/索引，不换集合名，不修改Mongo库名、server/.env、server/uploads或已有环境变量。

不迁移生产数据作为自动开发步骤；部署者需执行并确认退出码。索引未安装不能保证并发上限，应在开放新入口前完成。回滚旧应用前保留索引及新字段，不删除旧凭证；若仍有宽限中的连接，需先协调换到当前新令牌，否则旧版本不会识别宽限哈希。没有新增环境变量。

脚本仍保留 create/list/rotate/revoke；显式宽限写法：

```sh
npm run integration:credential -- rotate --id <credentialId> --grace-seconds 86400
```

这会在受控终端仅显示新令牌一次，不得把输出重定向进项目日志或提交。

## 验证与界面

契约：新增六个私有管理操作（操作级 servers=/api/projects/integrations），GlobalSiteC2* 独立组件和冻结快照；旧基础/报价/C1快照不变，S1草案不发布。校验脚本验证旧定义、两份新快照及28项拒绝错误改动回归。管理API响应按真实OpenAPI用AJV验证。

测试包含角色/组织/项目隔离、Cookie CSRF、服务凭证拒绝、宽限截止和吊销、并发轮换、12个并发创建最多3个成功、旧凭证占用和过期席位释放、套餐回退、当前角色变更、幂等迁移、明文不落库/不进审计或列表。浏览器使用临时数据库、虚构组织和真实API，验证创建→复制→关闭→刷新→轮换→吊销、中英、375px、横屏、深色、大字号、无横向溢出；复制测试使用页面内替身，不改变用户操作系统剪贴板，不记录令牌截图/trace。

界面沿用CRM现有组件与语义颜色；技能两次检索偏宣传页，不采用其未匹配的视觉方向，按通用可访问性原则核对标签、键盘、焦点、44px操作目标和响应式。生产HTTPS与客户的真实GlobalSite连接联调不在本次隔离测试中。
