## 迁移与上线

新增 integrationpublicresources（组织/项目/类型/源ID唯一、增量索引）与 integrationratelimits（凭证/分钟唯一、expiresAt TTL），不修改任何旧集合名。生产部署前执行 server 下 npm run integration:public -- indexes，可重复执行；随后按 C1-read-api.md 审核发布资料并按最小权限重新签发 C1 凭证。无新增环境变量，沿用 PUBLIC_BASE_URL 配置公网HTTPS；没有配置时产品文字仍可同步，图片数组为空。CLI 不代替原项目归属迁移，无组织旧项目拒绝新读接口。

## 边界

没有 GlobalSite 调用方、公开资料管理 UI、原文件导出或原文自动摘要。S1 /globalsite/* 草案不实现。同期变动分页采用下一轮补取及重叠水位去重，定期全量对账处理删除；不是历史事务快照。超大产品库的物化增量索引应基于实际容量验证后另做。
