# 销售助手工作界面优化（2026-10-16）

## 面向业务员的使用顺序
打开销售助手后，先确认正在处理的客户，再直接描述工作或使用首封开发信、客户时间线、跟进与报价等快捷入口。

- **对话**：显示真实客户名称、地区、开发状态和邮箱情况。当前客户或邮件有待办时显示相关提醒；全项目待办数量在导航中显示。
- **待办**：优先列出待审核草稿，其次列出需补充资料、暂停或失败任务，最后展示准备中的工作。已结束记录通过筛选查看。列表范围为服务端返回的最近 30 项。
- **工具**：集中提供来信与提醒、批量写信、产品资料、操作记录，子页面可返回工具或切回对话、待办。
- **审核**：待办的“审核并去写信”打开已有草稿，由业务员核对后发送。发送成功后的跟进记录仍沿用现有业务流程。

## 信息层级和交互
六个功能入口缩为一行三个主要入口；会话选择器改为紧凑工具栏。移除占据顶部的长说明和大图标引导，保留输入框旁的审核发送提示。
详细执行步骤、客户摘要、执行历史与取消任务收进“处理详情”。自动准备规则默认折叠；产品资料优先阅读，新增及编辑按需打开。规则仍须显式保存才生效。
历史会话的分析操作使用会话对应的客户或邮件，打开结果时同步到对应业务页面。从消息、提醒或操作记录进入任务时定位该任务。
新会话从引导顶部开始。手机打开助手不主动聚焦输入框，避免遮挡内容。
