# POP3 收件与邮箱密码：本地验收记录

日期：2026-10-13。范围：个人邮箱配置、验证、手动/定时同步；已有 IMAP 账户和项目级 IMAP 保持兼容。

## 本次行为

- 个人邮箱收件可选择 POP3，新账户默认 POP3/995/SSL；旧账户继续使用 IMAP，不自动改动已保存的邮箱。
- POP3 使用 UIDL 标识去重，邮件序号变化不重复导入；复用 MIME 解析、附件限制和个人邮箱权限隔离。
- 不发送 DELE，不删除服务器邮件。大邮件跳过，失败邮件重试，并预留新邮件同步容量。
- POP3/995 校验证书；非隐式 SSL 连接要求 STLS 后才发送账号密码。连接和响应有超时及大小限制。
- 密码表单支持“邮箱密码／授权码”；SMTP 和收件共用加密凭据，编辑时留空保留已存密码。验证不发送邮件。
- SMTP 继续支持手动选择 SSL/TLS、STARTTLS 要求与端口，包括用户提供的 25/非隐式 SSL 配置。
