## 实际交付

现有AgentTask继续负责领取、租约、暂停/继续/取消和有限重试。客户/邮箱/知识/约定变化时新epoch重新准备，旧分析/草稿保留；变更后的旧摘要/入口不作为当前结果显示。推理期间变化安全停止，可显式重试。每次语义检查/重写都重验当前租约，旧进程不能在恢复后追加模型调用或提交晚到结果。

用户仍需打开草稿人工发送。新投递记录保留所审核draft ID；旧版本的接受回执不能完成新版本任务。首个版本沿用历史去重键，新epoch独立去重，不重复迁移旧跟进。测试只模拟数据库/替代投递回执，不发送真实邮件。
