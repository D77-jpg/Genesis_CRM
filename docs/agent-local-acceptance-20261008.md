## DeepSeek 客户分析失败

- 本地两次失败记录的错误码均为 `OPENAI_INVALID_STRUCTURED_OUTPUT`。
- 用虚构 MOQ 73、交期 19 天及多条虚构来源复现：HTTP 200，但响应状态 `incomplete`，原因为 `max_output_tokens`。3000 输出 token 中 1866 用于思考，最终 JSON 被截断。
- 仅对官方 DeepSeek 的结构化任务指定 `reasoning.effort=none`，保持现有输出上限和来源/权限/审批校验；普通对话与其他提供商不受该参数影响。完整性错误与 JSON 格式错误分别处理。
- 请求补充当前服务器时间，避免模型生成已过期的跟进建议；过期时间仍由服务端拒绝，不擅自改写为未来时间。
- 状态栏改为“模型已配置”，避免将配置存在误认为所有业务调用健康。

## 标签页空白占位修复

- 原因：Radix 为非活动页设置 `hidden`，但 Agent 标签页的 `flex` 显示样式覆盖了浏览器默认隐藏样式；空的对话页继续参与高度分配，把后续分析或记录内容挤向底部。
- 共享 TabsContent 添加 `data-[state=inactive]:hidden`，保留活动页的 flex 布局及滚动行为。
- 本地 5173 实际运行记录页复现：非活动对话页高度 367.5px；修复后高度 0，活动内容顶部从 484.5px 回到标签栏底部 117px。对话/运行记录切换通过。
- 使用真实 Tabs 组件和与 Agent 相同的高度结构，在隔离页面用虚构资料验证客户分析/对话/运行记录：1366×900、375×900 共 8 次状态检查全部通过；非活动页始终 display:none、高度 0，活动页紧接标签栏，分析标题仅保留正常 16px 内边距。
- 本次只验证布局，没有重新调用真实客户分析或执行保存草稿/安排跟进。临时页面位于忽略的缓存目录，验证后已关闭并清理；几何证据与前后截图保存于本地输出目录。
- 前端类型检查、生产构建、被修改组件 ESLint、3 项回复渲染和 20 项 guarded-braces 回归通过。


## 手动标签切换与运行记录详情

- 根因：自动选中工作流标签的 effect 同时依赖 `tab`，导致用户点击对话或运行记录后又被切回分析。改为仅在工作流 ID 变化时自动选中；手动切换保持生效。
- 工作流标签保持挂载，非活动页仍隐藏且高度为 0；客户分析、邮件分析和客户预览的本地编辑不会因切换被卸载。用现有未保存分析的“跟进目的”临时输入虚构测试文字，经过对话/运行记录/分析切换后保留，再还原；未点击保存。
- 每条工具/审批卡片改为可点击且支持键盘的按钮，详情展示真实执行摘要、审批状态、时间、操作范围，以及已关联模型运行的耗时和 Token；进入运行记录自动刷新，也提供手动刷新入口。
- 新增只读 `GET /agent/actions/:id`。记录及模型运行按当前用户/项目隔离；只输出白名单业务参数，不返回任意原始参数、提示词或密钥。恢复链接复用现有结果读取权限，客户负责人转移或结果删除后不可打开。
- 客户分析、邮件分析和客户预览可从详情恢复已有结果，保留原审批流程。未保存完整查询原文的普通旧记录明确显示仅有摘要；未关联模型运行的不伪造模型或耗时。
- 在 5173 从用户刚保存的真实客户分析记录恢复原结果，验证对话→运行记录→客户分析→对话→运行记录均保持选择、隐藏页高度为 0；未重新生成分析、未调用外部模型。
- 普通读取、已确认写入、取消记录详情与键盘 Enter/Escape 已页面核验；Escape 后详情关闭而 Agent 面板仍存在。1366×900 与 375×900 详情布局核验通过。
