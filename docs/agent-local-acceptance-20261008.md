## DeepSeek 客户分析失败

- 本地两次失败记录的错误码均为 `OPENAI_INVALID_STRUCTURED_OUTPUT`。
- 用虚构 MOQ 73、交期 19 天及多条虚构来源复现：HTTP 200，但响应状态 `incomplete`，原因为 `max_output_tokens`。3000 输出 token 中 1866 用于思考，最终 JSON 被截断。
- 仅对官方 DeepSeek 的结构化任务指定 `reasoning.effort=none`，保持现有输出上限和来源/权限/审批校验；普通对话与其他提供商不受该参数影响。完整性错误与 JSON 格式错误分别处理。
- 请求补充当前服务器时间，避免模型生成已过期的跟进建议；过期时间仍由服务端拒绝，不擅自改写为未来时间。
- 状态栏改为“模型已配置”，避免将配置存在误认为所有业务调用健康。
