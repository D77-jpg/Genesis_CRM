## 2. 新手 30 分钟路径

### 第 1 步：登录与检查（5 分钟）

1. 使用管理员发放的独立账号登录，首次登录修改密码。
2. 确认右上角项目名称；不同项目数据严格隔离。
3. 打开「新手引导」，补齐公司名、发件人、签名和默认模板。
4. 打开「邮件合规」，确认发件邮箱已验证。

### 第 2 步：小批量导入（5 分钟）

1. 客户列表 → 导入 Excel → 下载模板。
2. 先导入 10–20 条真实但非敏感的测试客户。
3. 检查预检结果中的重复、错误行和字段映射；确认后再导入全量。
4. 为测试客户设置负责人，确认业务员只能看到自己名下客户。

### 第 3 步：第一封开发信（10 分钟）

1. 打开一个测试客户 → 写开发信。
2. 选择模板，检查 `{{name}}`、`{{company}}` 等占位符。
3. 预览主题、正文、签名和退订链接。
4. 发送后在客户时间线和「开发信记录」确认状态；mock 模式只记录不投递。
5. 用真实邮箱给自己发一封，检查 SPF/DKIM/DMARC 和垃圾箱表现。

### 第 4 步：收回复与跟进（5 分钟）

1. 配置个人收件邮箱（IMAP/POP3）并测试连接。
2. 回复测试邮件，确认「邮件中心」和客户时间线出现 `mail_received`。
3. 将客户状态改为「已回复」，新增一条跟进并设置下次跟进时间。
4. 测试退订关键词，确认地址进入抑制名单。

### 第 5 步：报价与团队（5 分钟）

1. 在客户详情新增报价，填写币种、明细、有效期和付款方式。
2. 检查金额由系统计算、版本号生成、客户状态变为「报价中」。
3. 邀请一名业务员和一名只读成员，验证权限边界。
4. 在「套餐与用量」查看本月开发信、AI Token 和存储占用。
